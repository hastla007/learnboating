# learnboating

WordPress-/WooCommerce-Lernplugin für Bootsführerscheine (SBF, SRC, UBI, SKN, FKN).

- `konzept-wp-lernplugin.md` – technisches Umsetzungskonzept
- `content-source/boatingschool/` – unveränderter Content-Snapshot aus
  [`hastla007/boatingschool`](https://github.com/hastla007/boatingschool), Stand siehe `SOURCE.md`
- `tools/sync-source.sh` – Snapshot auf einen anderen Quell-Commit aktualisieren

Snapshot aktualisieren:

```bash
tools/sync-source.sh <commit|branch|tag>
```
